## Description

This repository contains the **UX resources** necessary to integrate in your services the IT-Wallet authentication flow and/or the issuance of an attestation from a touchpoint of Authentic Source (“Credential offer”). More information on the IT-wallet system available at the official website [wallet.gov.it](https:\\wallet.gov.it).

The following resources are made available:

| Resource | Italian (Default) | English |
|---|-|-|
| **`IT-Wallet-authentication`** | `Flusso ITA` | `Flusso ENG` |
| **`IT-Wallet-credential-offer`** | `Flusso ITA` | `Flusso ENG` |

The resources, available for both Figma and Sketch, provide a clear framework of how the IT-Wallet services should look like and how they should work, helping you maintain visual and functional consistency with the [technical specification of the IT-Wallet system]([url](https://italia.github.io/eid-wallet-it-docs/releases/1.4.7/en/) and the [Design Guidelines for Public Administration Websites and Digital Services]([url](https://docs.italia.it/italia/design/lg-design-servizi-web/it/versione-corrente/index.html)).

Please note: some features available in Figma (.fig) files may not be available and/or correct in .sketch files converted using the latest version of [fig2sketch](https://github.com/sketch-hq/fig2sketch). It is therefore recommended to always check the conversion result and declare the status of resources and this eventuality to users.

## Getting started

Download the latest available version on the [Releases](https://github.com/italia/design-it-wallet-ux-resources/releases) page. Each release includes the files for both Figma and Sketch. Once downloaded, you can open the files with the respective design software and start exploring the resources.

### How to link the library (UI Kit) to Figma files

The resources use components linked to the **version 3.8.0** of the UI Kit Italia (`UI-Kit-Italia`), that includes icons, typography, applied colours and shadows.

**How to link the library in Figma:**
1. Make sure to have a **Figma Pro account** or higher, requested to publsh and link the library.
2. Download `UI-Kit-Italia` library and the filesof the resources as said at the beginning of this paragraph.
3. Upload all the files in your Figma working space.
4. Publish the `UI-Kit-Italia` library in your Figma working space following the official guide: 
  - [Publish a library in Figma](https://help.figma.com/hc/en-us/articles/360025508373-Publish-a-library)
5. In each file "swap" the missing components and styles ("Missing libraries") with those from `UI-Kit-Italia` following the official guide: 
  - [Swap of a library in Figma](https://help.figma.com/hc/en-us/articles/4404856784663-Swap-style-and-component-libraries)


**Note for the free Figma accounts:**

With a free Figma account it's not possible to link a library.
