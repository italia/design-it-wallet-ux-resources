# Design IT-Wallet UX Resources

[![License](https://img.shields.io/github/license/italia/design-ui-kit.svg)](https://github.com/italia/design-ui-kit/blob/main/LICENSE)

## Descrizione

Questo repository contiene **le risorse UX** utili a integrare nei propri servizi il flusso di autenticazione con IT-Wallet e/o l'ottenimento di un attestato da un touchpoint della fonte autentica (“Credential offer”).

Sono messe a disposizione le seguenti risorse:

| Risorsa | Italiano (Default) | Inglese |
|---|-|-|
| **`IT-Wallet-authentication`** | `Flusso ITA` | `Flusso ENG` |
| **`IT-Wallet-credential-offer`** | `Flusso ITA` | `Flusso ENG` |

Le risorse, disponibili sia per Figma e Sketch, forniscono un quadro chiaro di come dovrebbero apparire e funzionare i due servizi per IT-Wallet, aiutando a mantenere una coerenza visiva e funzionale con gli standard del sistema e della Pubblica Amministrazione. 

Attenzione: alcune funzionalità presenti nei file Figma (.fig) potrebbero non essere presenti e/o non corrette nei file .sketch convertiti utilizzando la versione più recente di [fig2sketch](https://github.com/sketch-hq/fig2sketch). È consigliato pertanto controllare sempre il risultato della conversione e dichiarare lo stato delle risorse e questa eventualità agli utenti.

## Come iniziare

Scarica l'ultima versione disponibile nella pagina [Releases](https://github.com/italia/design-it-wallet-ux-resources/releases). Ogni rilascio include i file sia per Figma che per Sketch.

Una volta scaricati, potrai aprire i file con i rispettivi programmi di progettazione e iniziare a esplorare le risorse.

### Collegamento delle librerie (UI Kit) ai file in Figma

Le risorse utilizzano componenti collegati alla **versione 3.8.0** di UI Kit Italia (`UI-Kit-Italia`), che include icone, tipografia, colori e ombre applicati.

**Per collegare le librerie in Figma:**
1. Assicurati di disporre di un **account Figma Pro** o superiore, necessario per pubblicare e collegare le librerie.
2. Scarica le librerie `UI-Kit-Italia` e i file dei prototipi come descritto a inizio paragrafo. 
3. Carica tutti i file nel tuo spazio di lavoro su Figma.
4. Pubblica la libreria `UI-Kit-Italia` nel tuo spazio di lavoro su Figma seguendo la guida ufficiale: 
  - [Pubblica una libreria in Figma](https://help.figma.com/hc/en-us/articles/360025508373-Publish-a-library)
5. In ognuno dei file effettua lo "swap" dei componenti e stili mancanti ("Missing libraries") con quelli di `UI-Kit-Italia` seguendo la guida ufficiale: 
  - [Swap di una libreria su Figma](https://help.figma.com/hc/en-us/articles/4404856784663-Swap-style-and-component-libraries)


**Nota per gli account Figma gratuiti:**
Con un account Figma gratuito, non è possibile collegare la libreria direttamente.
